# Daylight — планувальник фокусу

Daylight — адаптивний React-застосунок для планування щоденних справ і зосередженої роботи. Це практична демонстрація **React Icons**, **React Toastify** та **React Idle Timer**: кожна бібліотека використовується для конкретної функції інтерфейсу.

## Демо

Переглянути опублікований застосунок можна за посиланням: **[hillel-react-library.vercel.app](https://hillel-react-library.vercel.app)**.

## Можливості

- Перегляд завдань на день і часу, запланованого для кожного завдання.
- Додавання нових завдань, позначення їх виконаними та видалення.
- Очищення списку від виконаних завдань.
- Автоматичне оновлення лічильників і відсотка денного прогресу.
- Увімкнення та призупинення режиму фокусування.
- Попередження про бездіяльність і можливість відновити сесію.
- Адаптивне компонування для мобільних і настільних екранів.

## Використані бібліотеки

### React Icons

Іконки з `react-icons/fi` використовуються для кнопок, станів і статистики: позначення виконаного завдання, додавання та видалення, фокусування, таймера й прогресу. Вони роблять дії швидко впізнаваними, а для доступності кнопки також мають текстові `aria-label`.

### React Toastify

`react-toastify` надає ненав’язливий зворотний зв’язок після дій: повідомляє, що завдання створене, виконане чи видалене, або пояснює, чому дію не вдалося виконати. Також toast-повідомлення інформує про автоматичне призупинення сесії. Контейнер сповіщень налаштований унизу праворуч.

### React Idle Timer

`react-idle-timer` стежить за активністю користувача під час роботи із застосунком. Після **45 секунд** бездіяльності з’являється попередження; через **60 секунд** сесія фокусу призупиняється. Користувач може продовжити сесію кнопкою у діалоговому вікні. Короткий інтервал вибрано для зручної демонстрації; у реальному продукті його можна збільшити.

## Локальний запуск

Потрібен встановлений Node.js і npm.

```bash
npm install
npm run dev
```

Vite виведе адресу локального сервера в термінал.

## Перевірка та production-збірка

Перевірити TypeScript і зібрати production-версію:

```bash
npm run build
```

Запустити lint:

```bash
npm run lint
```

Переглянути зібрану версію локально:

```bash
npm run preview
```

## Дані

Початковий список завдань є демонстраційним і зберігається в стані React. Завдання можна змінювати під час роботи із застосунком; після перезавантаження сторінки список повернеться до початкових значень.
