# Daylight — планувальник фокусу

Невеликий інтерактивний React-застосунок для планування завдань і демонстрації трьох бібліотек:

- **React Icons** — іконки в кнопках, індикаторах і списку завдань роблять дії зрозумілими без зайвого тексту.
- **React Toastify** — короткі повідомлення підтверджують додавання, виконання й видалення завдань, а також повідомляють про помилки та стан сесії.
- **React Idle Timer** — попереджає перед завершенням бездіяльної сесії, а потім призупиняє її; користувач може відновити роботу кнопкою в діалоговому вікні. Для швидкої демонстрації встановлено тайм-аут 60 секунд і попередження за 15 секунд до нього.

## Запуск

```bash
npm install
npm run dev
```

Перевірка збірки та типів:

```bash
npm run build
```

Початковий список завдань містить демонстраційні дані. Можна додавати, завершувати та видаляти завдання; статистика прогресу оновлюється автоматично.
